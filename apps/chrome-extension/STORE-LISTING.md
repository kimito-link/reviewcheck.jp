# Chrome Web Store 掲載情報（口コミチェック.jp）

このファイルは掲載文の下書きです。今回の変更はストアへ出していません。

## 拡張機能名
口コミチェック.jp｜Google口コミチェッカー

## 概要（短い説明・132文字以内）
今開いているページのGoogle口コミを簡易チェックし、スコアと要点を表示します。前回の点検は端末内だけに残します。

## 詳細な説明
Googleマップやお店のページを見ているときに、ツールバーのアイコンを押すと、そのページのGoogle口コミの状態を簡易診断します。

【できること】
・ポップアップを開くと、今のタブを診断し、スコアと要点を表示
・店舗名やGoogleマップURLを手入力して診断
・前回の点検日時と、1か月後の次の点検の目安を表示
・要約とWeb版の結果URLをコピー、または端末の共有機能で渡す
・詳しい診断結果をWeb版で確認

【こんな方に】
・店舗オーナー、クリニック・飲食店・美容院・整体院・士業の方
・自店舗や競合店舗の口コミ状況をサッと把握したい方

【プライバシー・権限について】
・権限は activeTab と storage。閲覧履歴を常時収集することはありません。
・診断は、ポップアップを開いたときと手入力したときに、その対象のURLまたは店舗名を当サービスのAPIへ送って行います。
・前回の点検日時と要点は chrome.storage.local（この端末の拡張の保存領域）だけに残します。
・口コミの購入・偽レビュー・やらせ・競合への低評価工作などの不正行為は行いません。

【ご注意】
本診断は公開情報・入力情報をもとにした簡易診断です。検索順位・来店数・口コミの件数・星の数が上がることを約束するものではありません。表示される数値は目安です。
