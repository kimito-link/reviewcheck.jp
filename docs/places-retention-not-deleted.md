# 消していない記録

この下書きは、記録を消しません。本番の Redis、KV、ブラウザ、拡張の保存領域には接続しません。

## 残しているもの

- `rc:store:v1:*` `rc:comp:v1:*` `rc:comp:v2:*` `rc:nearby:v1:*` `rc:cohort:v1:*`
- 監視のスナップショット `mc:snapshot:*` と、既存の監視対象
- ブラウザの `rc:last:*`。Google の結果では読まない。キーは消さない
- 拡張にすでに入っている古い点検。新しい保存は Place ID と日時だけ
- 古い共有 URL。パスに過去の内容が残る。画面は Place ID 以外を使わない。パスからは消せない

## 承認があるまで実行しない手順

1. 対象が本番か、捨ててよい検証用かを人が確認する。
2. 既存の有料契約の有無を、決済の記録で確認する。コードからは分からない。
3. 契約者への連絡と、停止・返金の要否を、このリポジトリの外で決める。
4. その後にだけ、キーの期限切れまたは削除を、対象の環境で実行する。

`retentionCleanupPlan()` は `executable: false` を返すだけで、削除関数はありません。
